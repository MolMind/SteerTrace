# 客户端适配

所有客户端保持相同的用户入口：“分析这个会话”，或通过客户端技能入口调用 `steer-trace`。
路径、会话 ID、历史分页和触发消息截断由 Agent 根据实际开放的能力处理。

## 读取原则

指定文件或会话优先；否则读取当前会话。排除触发分析的用户消息及之后的全部内容。
指定的项目文档作为辅助证据，不自动扫描项目或账户历史。

客户端官方机制、当前环境是否开放、实际调用是否成功，是三个不同层次。
只有状态或摘要的接口不能当作完整原始会话；不能定位当前身份时也不能选择最近修改的文件。

## 各客户端入口

| 客户端 | 优先方式 | 适配边界 |
| --- | --- | --- |
| Codex | 已开放的 App Server 完整历史分页；本地可用时按当前会话 ID 定位 transcript | 默认摘要不足；不能假定所有桌面或云端会话都有本地文件 |
| Claude Code | Skill 当前会话 ID 替换；已有 hook 提供的 transcript 路径 | Skill 替换值不等于 shell 环境变量；hook 数据需要实际可用 |
| DeepSeek Harness | 已启用的会话事件读取工具或授权宿主查询接口 | 查询工具是可选能力；人类界面的导出动作不是模型工具 |
| 其他 Agent 客户端 | 原生完整历史接口，或明确绑定的 transcript 路径 | 需保留消息角色、ID、原文和覆盖信息 |

执行时的具体方法、参数与官方来源集中维护在 Skill 的
[会话选择规则](../../skills/steer-trace/references/session-selection.md)，避免两份规则漂移。

## 受限环境

只有聊天、不能访问本地文件或执行命令的环境，无法直接运行完整报告流程。
仅支持 MCP 的客户端需要适配服务，本项目当前不提供 MCP 服务。

Agent 先尝试当前环境支持的读取方式；确实无权限、无原始历史或无可靠身份时，
才请求缺失材料。安装 Skill 不会绕过客户端权限，也不会将摘要重建为原始对话。
