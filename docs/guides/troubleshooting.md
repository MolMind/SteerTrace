# 常见问题

- **找不到 Skill**：核对客户端的安装机制，确认安装的是 `skills/steer-trace/`，
  并按客户端实际要求重新加载。Python 包安装和 Skill 注册不是同一件事。
- **找不到命令**：使用安装环境内的 CLI 绝对路径；检查[安装指南](installation.md)。
- **找不到配套文档**：安装时须保留完整 checkout，不能只复制单个 SKILL.md。
- **读不到当前会话**：检查客户端实际提供的原始历史、会话身份和访问权限。
  已知当前 ID 才能定位文件，不能改用最近的聊天。见[客户端适配](clients.md)。
- **触发消息找不到或有重复**：使用准确的用户消息 ID；原文匹配必须完整且唯一。
  尚未落盘的消息需要稳定快照或重试，不能跳过截断检查。
- **Claude 分支不明确**：依据当前分支信息指定 `--leaf-id`，不混合兄弟分支。
- **会话不完整，prepare 拒绝继续**：先核对覆盖说明；接受具体缺失后才使用 `--allow-partial`。
- **输出已存在**：更换输出文件或运行目录，不覆盖已有证据。
- **引用校验失败**：对照冻结证据修正分析，不修改证据来让检查通过。

参数说明使用 `steertrace --help` 或 `steertrace <子命令> --help`。
格式、大小上限和不支持的历史类型见[输入格式](../reference/input-formats.md)。
