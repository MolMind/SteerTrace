# 第二轮：事实边界与评测适用性优化

本轮先冻结优化前快照，再修改核心分析规范，最后用新写材料比较。第一轮产出与评分保持原样。

## 已实现的规范修正

- 对影响批评、归责或方向的主要结论，核对要求、授权、计划、尝试、完成报告及可见结果。
  动作状态与来源/验证强度分开判断；不将指令升级为执行，也不将充分记录一律降为未知。
- 数字同时核对单位、比较方向、对象、时间范围与用途。回退、验收和预算标准不能自动互换。
- 主句保持证据边界，不能先断言更强事实再靠免责声明补救。
- 方向关联可观察的判断变化、可能削弱或限制方向的证据，以及结果成功仍未排除的相关解释。
  产品验收与判断方式改善分别评价，允许根据新证据修正或撤回方向。

这些检查写入 Skill 的分析方法及生成的 ANALYZE 指引，复用已有解释和不确定性字段，未新增产品必填字段。
它们是针对首轮失误的改进假设，规范更新本身不证明产出质量已经提高。

## 新材料与固定比较臂

[新语料](../../examples/quality/round2/cases.json) 为 12 个虚构案例，每例 16 条消息，
共 6 组严格单消息差异配对；三个主题为 dev，三个为公开冻结的 holdout。
具体边界见[语料说明](../../examples/quality/round2/dataset-notes.md)。
第一轮材料已用于优化，不能继续作为未见材料。新材料在冻结后不再为了评分修改。

三臂为 before（第一轮核心规范的原样快照）、after（本轮优化规范）和 generic（相同通用复盘基线）。
[来源摘要](../../examples/quality/round2/provenance.json)记录快照与源文件哈希。
各臂仍使用共同 JSON，比较分析内容，不比较会话获取或原生报告格式。

## 评测工具变更

准备本轮任务：

```bash
python3 scripts/compare_quality.py prepare --cases examples/quality/round2/cases.json --comparators examples/quality/round2/comparators --output runs/quality-round2-new --repeats 3 --opaque
```

- 任务使用不含主题的编号，路径为 `generation/<arm>/rN/Txxxx.md`；产出保存在对应 `outputs` 路径。
  生成者只读取被分配的提示，不接收 case ID、分组、配对、答案或方向适用性。
- 评分细则、输出契约、任务映射、适用性与原始材料在 prepare 时一并冻结，实际提示文件也记录哈希。
- 每个案例的方向政策提前确定为 required、unnecessary 或 insufficient。它决定应否允许合理留空，
  不依据某一臂最终有没有写建议来选择样本。
- required 却留空必须标 omitted，方向价值与可检验性给零；这是对实际遗漏的评分，不是将缺失输出补零。
  缺失输出继续默认拒绝，或显式记录不完整覆盖。
- unnecessary/insufficient 下合理留空标 appropriate_empty，可不适用；非空建议必须实际评质量，
  根据依据与增量价值标 supported、unwarranted 或 unsupported，不能机械罚所有额外建议。
- 先单列严重错误、遗漏和无依据建议，再看维度质量与逐案胜负。按同案例同轮次配对；
  分别报告每次结果、最差表现和三次范围，重复产出数不能当作新增独立案例数。
- 原有第一轮 manifest、评分与配对评审仍可读取；真实旧运行重算的维度均值与胜负计数保持一致。

生成后使用 `blind`，评审者只读匿名包、冻结 rubric 和评分模板。除原有字段，新评分须有
`direction_assessment`。使用 `summarize --pair-ratings ...` 汇总方向分类及配对响应。
三次生成各使用新上下文，各批次中的多个案例仍共享上下文；宿主未暴露的精确模型与 token 参数保持未知。
严重错误、低证据评分和有争议的方向项需由第二个新上下文在不知原评分的条件下复核；保留两次记录，
不静默替换初评分数，不把同宿主不同上下文当成跨模型验证。

## 完成结果：2026-11-16

已完成108份产出、108份匿名初评、54组配对评审，并按预定规则复核30份（21异常项、9随机项）。
复核方向分类30/30一致，6份存在评分差异；原始初评不变。政策约束下的一致不等于政策本身正确。

共同案例上证据忠实均分：优化版4.00、优化前3.94、通用复盘3.83；初评均无严重错误。
但required方向遗漏分别为10/24、8/24、0/24，通用复盘另外有3份无依据建议。
优化版并未通过整体质量提升的验收，不能只引用事实分数宣布全面更好。
方向遗漏来自预设政策，部分为合理行为的延续方向，并非等量事实错误；下一步应明确合理留空与遗漏的边界，
再用新材料验证，不能在本批已见材料上反复调参并宣称泛化改善。
