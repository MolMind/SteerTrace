# v0.1.0 验证记录

日期：2026-11-13。本页记录首版实现与可复现验证，不包含私人会话材料。

## 交付范围

- Python 3.9+ 本地包与 import、prepare、validate、report 四个命令，无运行时第三方依赖。
- 显式导入通用 JSON、Codex JSONL、基本父子链 Claude Code JSONL，记录分支与覆盖限制。
- 指定 Markdown 快照、哈希、证据分包与 Agent 分析模板。
- 校验原话、角色、顺序、归因条件、文档引用及建议状态。
- 固定 HTML 渲染器、内嵌 CSS/JS/SVG；圆润内容区、自然留白、无分隔线的阅读布局。
- 滚动导读、步骤切换、搜索筛选、证据展开、阅读进度及打印/PDF。
- 中英文使用说明、事件规范、Skill 与报告表达规范、贡献指南、版本记录和许可证。
